IOS 接入
从官网下载Playsout SDK 并解压缩，可以放到跟项目根目录同级，目录结构如下：
```
- PlaysoutSDK-ios
- YourProject
- ...
```
playsout sdk是用flutter写的，所以需要在ios项目中引入flutter的代码。
在ios项目中引入flutter的代码可以参考[flutter官方文档](https://flutter.dev/docs/development/add-to-app/ios/project-setup)。
